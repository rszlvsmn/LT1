# LT1 Part 2: Hands-on Programming activity

## Description:
### This python program of mine asks the user to input the radius of a circular garden in meters. Then, it computes for the area, circumference, square root of the area ( all three are printed to two decimal places.) It also computes for the area rounded up and down to the nearest whole number. It calculates all these and prints them out immediately after the user enters the radius.
## How to run:
### - First, you open the python program
### - Secondly, You enter the radius of the circular garden
### - Lastly, you get the area, circumference, square root of the area, and the area rounded up and down to the nearest whole number.
## Input Needed:
### - You need to input the radius of the circular garden in meters.
## Sample Output:
### - Enter the radius of the circular garden in meters: 5
The area of the circular garden is: 78.54 square meters
#### The circumference of the circular garden is: 31.42 square meters
#### The square root of the area is: 8.86
#### The area rounded down to the nearest whole number is: 78 square meters
#### The area rounded up to the nearest whole number is: 79 square meters
